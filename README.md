# fieldcraft (Vibeclones mirror)

Hosted browser (WebAssembly) builds of [fieldcraft](https://github.com/tangency-labs/fieldcraft), an open-source modeler for structures, heat and fluids, by [Tangency Labs](https://github.com/tangency-labs). The code is theirs; this repo only builds and hosts it.

- Latest: `/fieldcraft/latest/`
- A specific version: `/fieldcraft/v<version>/`
- Version list: `/fieldcraft/versions.json`

Each version is built from an upstream release tag, for example `/fieldcraft/v0.6.0/`. A scheduled workflow builds new ones.

Upstream is licensed Apache-2.0. Every version folder includes the license and a `SOURCE.txt` naming the exact upstream tag it was built from.
